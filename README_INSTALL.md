## Установка в репозиторий

Скопировать содержимое пакета в корень проекта RustyRage, сохраняя структуру каталогов. Если в проекте уже есть `AGENTS/`, не заменять каталог целиком: добавить файлы TASK_003, сверить существующие правила и не перезаписывать общие инструкции.

Файл задачи намеренно находится в `TASKS/draft/`, а не в `TASKS/active/`. Не переносить его в `active` и не запускать реализацию до выполнения всех условий активации.

## Условия активации TASK_003

1. Владелец явно подтверждает `TASK_002 ACCEPTED` после просмотра его итоговых артефактов. Сообщённый DeepSeek `PASS` сам по себе не заменяет owner acceptance.
2. Владелец принимает или корректирует все решения из `TASKS/draft/TASK_003_OWNER_DECISIONS.md`.
3. Владелец утверждает финальный scope, Stage/Gate последовательность и критерии Gate A–E.
4. Владелец явно разрешает активацию: только после этого исполнитель может переместить/скопировать утверждённую задачу в `TASKS/active/TASK_003_FIRST_PLAYABLE.md`.
5. Владелец отдельно разрешает реализацию. До этого агентам разрешены только чтение, аудит и подготовка отчётов без изменения исходного кода.

## Роли

- **DeepSeek через Harness:** исполнитель. Работает только в разрешённом Stage, останавливается на каждом Gate и ждёт решения владельца.
- **Google:** независимый архитектор/аудитор. Проверяет архитектуру и diff, не реализует код и не подменяет решение владельца.
- **ChatGPT:** независимый итоговый аудитор. Проверяет предоставленные diff, тесты, логи и отчёты; не объявляет Gate принятым от имени владельца.
- **Владелец:** утверждает решения, открывает Stage, принимает Gate и разрешает переход к следующему этапу.

## Важные ограничения

- Не изменять `TASK_002` и его отчёты в рамках `TASK_003`.
- Не менять зафиксированные версии зависимостей без отдельного решения владельца.
- Не объявлять платформу VERIFIED без фактической сборки/тестов на ней.
- Не создавать сетевую реализацию в First Playable; только сохранить корректные границы будущей сетевой архитектуры.
- Не добавлять VIN, оружие, повреждения, ботов, аудио, PBR и production art в First Playable.
- Не считать текущее содержимое этого пакета проверенным против живого репозитория: перед активацией исполнитель обязан сверить реальные файлы, API и target graph.
