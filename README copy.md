# RustyRage — стартовый пакет DeepSeek / Harness

**Версия архитектуры:** `0.1`  
**Статус:** архитектурная база утверждена; зависимости и платформенные реализации подлежат технической верификации.  
**Первая задача:** `TASK_001: Foundation Smoke Test`.

## С чего начать

1. Прочитать [`AGENTS.md`](AGENTS.md).
2. Прочитать [`PROJECT_CONTEXT/README.md`](PROJECT_CONTEXT/README.md) и [`PROJECT_CONTEXT/ARCHITECTURE_STATUS.md`](PROJECT_CONTEXT/ARCHITECTURE_STATUS.md).
3. Ознакомиться с индексом [`SPECIFICATIONS/README.md`](SPECIFICATIONS/README.md).
4. Выполнять только активную задачу [`TASKS/active/TASK_001_FOUNDATION_SMOKE_TEST.md`](TASKS/active/TASK_001_FOUNDATION_SMOKE_TEST.md).
5. Записывать фактические результаты и логи в `REPORTS/`.

## Важно

- Это пакет документации для передачи DeepSeek через **Harness**. Это не инструкция для Cline и не набор `.clinerules`.
- Архитектура `0.1` заморожена. Изменение утверждённых решений требует согласования владельца проекта.
- `PROPOSED` не означает, что библиотека проверена или обязана быть использована.
- Не заявлять `PASS` без фактического запуска на соответствующей платформе.
- Первая задача создаёт фундамент настоящей игры, а не одноразовую демонстрацию. При этом реализация полного геймплея в `TASK_001` запрещена.
