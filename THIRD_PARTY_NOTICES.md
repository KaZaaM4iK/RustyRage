## Required dependency record for every added/updated library

- exact immutable commit SHA or release archive checksum;
- exact source URL and retrieval method;
- license file and copyright notices for that revision;
- transitive dependencies and their exact versions;
- enabled optional components;
- local patches and reasons;
- platforms actually built and run;
- whether the dependency is runtime, build-time, test-only or host-only.

Do not add a library solely because it appears in this notice file. The active task and owner-approved decisions define dependency scope.
